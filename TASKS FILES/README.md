# 📊 ScreenSense: Kids’ Screen Time Behavior Analysis

## 📌 Project Overview  
ScreenSense is a data analytics project focused on understanding children's screen time behavior.  
The goal is to move beyond raw data and generate meaningful insights that can help **parents, educators, and decision-makers** take informed actions.

This project analyzes how factors such as **age, gender, location, device type, and activity type** influence screen usage patterns.

---

## 🎯 Objectives  
- Analyze screen time trends among children  
- Identify high-usage and high-risk groups  
- Understand behavioral drivers (educational vs recreational usage)  
- Present insights through interactive dashboards  

---

## 📂 Dataset  
**Source:** Kaggle – *Indian Kids Screentime 2025*  

**Features include:**  
- Age group  
- Gender  
- Urban/Rural location  
- Device type  
- Daily screen time  
- Activity category  

---

## ⚙️ Project Workflow  

### 🔹 Data Preparation  
- Loaded and explored dataset  
- Handled missing values  
- Cleaned inconsistent data  
- Feature engineering:
  - Age bands  
  - Weekday/Weekend flags  
  - Device & activity ratios  

---

### 🔹 Exploratory Data Analysis (EDA)  
- Analyzed distribution of screen time  
- Compared usage across:
  - Age groups  
  - Gender  
  - Location  
- Visualizations used:
  - Histograms  
  - Bar charts  
  - Box plots  

---

### 🔹 Device & Activity Analysis  
- Identified most used devices  
- Compared educational vs recreational usage  
- Observed demographic patterns  

---

### 🔹 Cohort & Behavioral Insights  
- Identified high-risk (heavy usage) groups  
- Performed cohort analysis (Age × Device)  
- Used heatmaps and comparisons  

**Key Observation:**  
> Older children using mobile devices tend to have the highest screen time.

---

### 🔹 Dashboard Development  

Built an interactive dashboard using **Power BI / Tableau**:

#### 📍 Page 1: Screen Usage Overview  
- KPI metrics (average screen time, % exceeding limits)  
- Device usage patterns  
- Age distribution  

#### 📍 Page 2: Demographic Analysis  
- Screen time by age, gender, location  
- Device preferences across groups  

#### 📍 Page 3: Behavioral Insights  
- Cohort analysis (Age × Device)  
- Educational vs recreational usage  
- High-risk usage patterns  

---

## 🎛️ Dashboard Filters  
- Age Band  
- Gender  
- Urban/Rural  
- Device Type  
- Usage Level  

---

## 📈 Key Insights  
- Screen time increases with age  
- Mobile devices dominate usage  
- Urban children show slightly higher exposure  
- Recreational usage drives total screen time  
- Portable devices are more likely to exceed limits
