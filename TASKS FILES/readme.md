📊 ScreenSense: Kids’ Screen Time Behavior Analysis
📌 Project Overview

ScreenSense is a data analytics project focused on understanding children’s screen time behavior. Instead of just analyzing raw numbers, this project transforms data into meaningful insights that can help parents, educators, and decision-makers make informed choices.

The study explores how factors such as age, gender, location, device type, and activity type influence screen usage patterns among children.

🎯 Objectives
Analyze screen time trends among children
Identify high-usage and high-risk groups
Understand behavioral drivers (educational vs recreational usage)
Present insights through interactive dashboards

📂 Dataset
Source: Kaggle – Indian Kids Screentime 2025
Key Features:
Age group
Gender
Urban/Rural location
Device type
Daily screen time
Activity category

⚙️ Project Workflow

🔹 1. Data Preparation
Loaded and explored the dataset
Handled missing values
Cleaned inconsistent data
Feature engineering:
Age bands
Weekday/Weekend flags
Device & activity ratios

🔹 2. Exploratory Data Analysis (EDA)
Analyzed distribution of screen time
Compared usage across:
Age groups
Gender
Location
Visualizations used:
Histograms
Bar charts
Box plots

🔹 3. Device & Activity Analysis
Identified most commonly used devices
Compared educational vs recreational usage
Observed patterns across demographics

🔹 4. Cohort & Behavioral Insights
Identified high-risk (heavy usage) groups
Performed cohort analysis (Age × Device)
Used heatmaps and comparative analysis

Key Observation:

Older children using mobile devices tend to have the highest screen time.

🔹 5. Dashboard Development

An interactive dashboard was created using Power BI / Tableau.

📍 Page 1: Screen Usage Overview
KPI Metrics:
Average screen time
% exceeding recommended limits
Device usage patterns
Age distribution
📍 Page 2: Demographic Analysis
Screen time by age, gender, and location
Device preferences across groups
📍 Page 3: Behavioral Insights
Cohort analysis (Age × Device)
Educational vs recreational usage
High-risk usage patterns
🎛️ Dashboard Filters

The dashboard includes interactive filters for dynamic analysis:

Age Band
Gender
Urban/Rural
Device Type
Usage Level
📈 Key Insights
Screen time increases with age
Mobile devices dominate overall usage
Urban children show slightly higher exposure
Recreational usage significantly drives total screen time
Portable devices are more likely to exceed recommended limits
