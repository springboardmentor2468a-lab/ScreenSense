📊 ScreenSense: Kids’ Screen Time Behavior Analysis
📌 Project Overview

This project focuses on analyzing children's screen time patterns and understanding how different factors like age, gender, location, device type, and activity influence their screen usage.

The main idea behind ScreenSense is simple — instead of just looking at numbers, we try to turn data into meaningful insights that parents, educators, and decision-makers can actually use.

🎯 Objective
Analyze screen time trends among children
Identify high usage patterns across different groups
Understand behavioral drivers like recreational vs educational usage
Present insights through interactive dashboards
📂 Dataset
Source: Kaggle – Indian Kids Screentime 2025
The dataset includes information such as:
Age group
Gender
Urban/Rural location
Device type
Daily screen time
Activity category

📈 Key Insights
Screen time generally increases with age
Mobile devices dominate usage
Urban children show slightly higher exposure
Recreational usage strongly impacts total screen time
Portable devices are more likely to exceed limits
