PAGE 1 — Overview
1. Bar Chart — Screen Time By Location

Y axis → Location (Urban / Rural)

2. Clustered Bar Chart — Average Daily Screen Time By Age Group and Gender

X axis → Average Daily Screen Time (hours)
Y axis → Age Group
Legend → Gender (Male / Female)

3. Clustered Bar Chart — Screen Time Category Distribution

X axis → Count of Kids
Y axis → Screen Time Category (Low / Medium / High)

4. Card — Total Average Daily Screen Time

Single number → Sum of avg daily screen time in hours

5. Card — Educational to Recreational Ratio

Single number → Ratio value

6. Card — Health Issue %

Single number → Percentage of kids with health issues

7. Slicers

Age Group → filter by age
Gender → filter by male or female
