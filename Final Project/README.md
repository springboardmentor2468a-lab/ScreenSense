# 📊 ScreenSense: Kids Screen Time Analysis

## 📌 Project Overview

ScreenSense is a data analysis project focused on understanding screen usage patterns among children. The goal is to identify behavioral trends, device preferences, usage habits, and the impact of screen time on health.

This project combines data visualization, cohort analysis, and sentiment analysis to derive meaningful insights that can help in promoting healthier digital habits.

---

## 🎯 Objectives

* Analyze screen time distribution across different categories
* Identify patterns based on device usage and duration
* Perform cohort analysis to segment user behavior
* Understand health impacts caused by excessive screen usage
* Generate actionable insights for better screen time management

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 📊 Analysis Performed

### 1. Exploratory Data Analysis (EDA)

* Distribution of device usage
* Screen time duration patterns
* Usage behavior across weekdays and weekends

### 2. Cohort Analysis

* Segmentation based on **Duration_Category × Device_Type**
* Identification of high-risk usage groups

### 3. Sentiment Analysis

* Categorization of health impacts into:

  * Negative
  * Neutral
* Understanding correlation between screen time and health issues

### 4. Behavioral Insights

* Usage focus (Recreational vs Educational)
* Device preference trends
* Screen time exceedance patterns

---

## 📈 Key Insights

* High screen time (4+ hours) is common among users
* Recreational usage dominates over educational usage
* Majority of users experience negative health impacts
* Poor sleep is the most frequently reported issue
* Users exceeding screen limits show stronger negative effects
* Portable devices are the most widely used
* Weekend usage is slightly higher than weekday usage
* Higher duration correlates with increased health risks

---
## 📢 Conclusion

This project highlights how excessive screen time affects children's health and behavior. By analyzing patterns and trends, it provides valuable insights that can help parents, educators, and policymakers encourage healthier screen habits.
