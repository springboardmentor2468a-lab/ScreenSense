Page 1: Overall Screen Time Overview
    Visual 1: Card – Total Number of Users
          I used a card visual to show the total number of users in the dataset.
               This helps viewers understand the size of the dataset before analyzing detailed patterns.
   Visual 2: Histogram / Column Chart – Screen Time Distribution
                 This chart helps analyze the distribution of average daily screen time among users.
                       It shows whether most users spend low, moderate, or high screen time, which helps identify overall usage patterns.
     Visual 3: Donut Chart – Urban vs Rural Users
                  helps quickly understand the percentage of users from urban and rural locations.
     Visual 4: Bar Chart – Device Usage Distribution
                   The bar chart compares how many users prefer different devices such as smart phone, laptop, tablet, or TV.
                         This helps identify the most commonly used device.

Page 2: Demographic Analysis
           Visual 1: Bar Chart – Screen Time by Age Band
                  This chart compares screen time across different age groups. 
                     It helps identify which age group spends more time on screens.
          Visual 2: Grouped Bar Chart – Screen Time by Gender
                 A grouped bar chart allows comparison between male and female users.
                    This helps identify differences in screen time behavior across genders.
           Visual 3: Stacked Bar Chart – Device Usage by Age Band
                   This visual shows which devices are preferred by different age groups. 
                          It helps analyze how device preferences vary across age segments.
Page 3: Activity and Habit Patterns
          Visual 1: Grouped Bar Chart – Activity Type by Weekday vs Weekend
                   This chart helps analyze habit patterns, showing how users spend time 
                            on educational vs recreational activities during weekdays and weekends.
           Visual 2: Stacked Bar Chart – Device Usage by Weekday vs Weekend
                This chart compares device usage patterns on weekdays and weekends.
                               It helps understand whether device preferences change depending on the day.
           Visual 3: Box Plot – Screen Time by Age Band
                A box plot helps analyze screen time distribution and detect outliers in different age groups. 
                     It provides a better understanding of variation in screen usage.
Page 4: Cohort and Segment Analysis
           Visual 1: Heatmap / Matrix – Age Band × Primary Device
                This visual helps identify top cohorts, which are groups with the highest usage. 
                       For example, it shows which age group uses which device the most.
            Visual 2: Stacked Bar Chart – Activity Type by Location
                This chart compares activity behavior between urban and rural users. 
                      It helps identify whether location affects screen usage patterns.
