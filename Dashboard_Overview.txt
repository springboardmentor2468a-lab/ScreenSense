📊 Dashboard Overview – Kids Screen Time Analytics

The Kids Screen Time Analytics Dashboard is an interactive Power BI solution designed to analyze screen usage patterns, behavioral trends, and health risks among children across different age groups.

This dashboard provides a multi-dimensional view of screen time, helping identify excessive usage, understand its drivers, and evaluate its impact on health and lifestyle.

🔹 Key Highlights
Tracks 10K+ children records across age groups (Kids, Teens, Young, Adults)
Monitors average screen time (~4.37 hours/day)
Identifies % of users exceeding recommended limits (86%)
Evaluates screen time distribution by gender, location, and device type
Analyzes usage behavior (Education vs Recreation)
Detects high-risk users (~6%) based on screen habits and health impact
🧩 Dashboard Structure
1️⃣ Overview Page
KPI cards for total users, average screen time, and risk levels
Screen time trends across age groups
Usage purpose breakdown (Education vs Recreation)
Gender-based screen time distribution
Device-wise screen time comparison
Urban vs Rural behavior analysis
Gauge showing actual vs recommended screen time
2️⃣ Demographics Page
Screen time comparison across age groups and gender
Device access split (Personal vs Shared)
Device ownership trends by age
Hierarchical view of device usage patterns
Average screen time by primary device
Trend analysis split by gender
3️⃣ Behaviour Page
Relationship between screen time and learning behavior
Usage pattern comparison across screen time levels
Distribution of education vs recreation usage
Variability in screen time (box plot insights)
Shift in usage preference across age groups
Contribution of usage type to overall screen time
4️⃣ Risk Analysis Page
Health impact breakdown (eye strain, anxiety, sleep issues, obesity risk)
Risk level distribution across screen time categories
Impact of exceeding screen limits on health outcomes
Key drivers of high-risk behavior (age, device, usage type)
Health impact comparison across age groups
Overall health impact distribution
5️⃣ Insights Page
Summarized findings from all analysis layers
Identification of key risk factors and usage patterns
Actionable recommendations for reducing screen time risks
Focus on high-risk groups (Teens, smartphone users, recreation-heavy usage)
🎯 Objective

The primary goal of this dashboard is to:

Identify screen overuse patterns among children
Understand behavioral drivers of screen time
Analyze health impacts linked to excessive usage
Enable data-driven decisions for parents, educators, and policymakers
🛠️ Tools & Techniques Used
Power BI (Data Visualization & Dashboard Design)
Data Modeling & Relationships
DAX Measures for KPIs and Calculations
Interactive Filters & Navigation (Bookmarks, Buttons)
🚀 Outcome

This dashboard transforms raw screen time data into actionable insights, helping stakeholders:

Detect high-risk users early
Promote balanced screen usage
Improve children’s health and well-being
